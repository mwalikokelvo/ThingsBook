# jotter — guide for AI coding agents

Several assistants (Claude, Codex, Gemini) work on this repo.

- Start here: read `HANDOFF.md` before any work, and append your result to it when you finish.
- Before new work, check recent branches (`claude/*`, `codex/*`) and continue from what others finished instead of starting over.
- Branches: Claude works on `claude/<topic>`. Never merge to `main` and never force-push; the user decides merges.
- Verification labels, exactly one per claim: `tested` (ran here and passed), `compiled`, `CI-built`, `installed`.
- Default style: smallest complete change.
