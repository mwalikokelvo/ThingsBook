# Specialist roster

Find the expert for a slice here, then print its persona with `python3 scripts/persona.py <id>` (each division is bundled in `agents/<division>.md`) and put it in the worker's brief — see `references/specialists.md` for how. The id is the file name without `.md`, the same id the runbooks use.
