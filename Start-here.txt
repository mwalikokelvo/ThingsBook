ThingsBook 1.15.0 - start here

Windows: ThingsBook-Independent-1.15.0.exe
Android: ThingsBook-Android-1.15.0.apk
Both are on the GitHub Releases page with checksums. Update Android over the existing
installation; do not uninstall or clear app data, because that removes the private on-device
library. Keep your existing private voice pack. The APK is signed with the original key.
Full history of every version: CHANGELOG.md.

What 1.14.3 adds (details in CHANGELOG.md):
- Long listening with the screen off: a PDF page that was being drawn when the screen turned off
  now opens, and on Windows the PC no longer suspends ThingsBook while reading aloud.
- 1.14.2: PDFs keep reading past a page end with the screen off (Android); "Keep reading in
  background" is on by default (turn it off in Voice); Details in the reader heading edits a
  book's title and author; chapter names come from the table of contents.
- 1.14.1: turning the page no longer stops reading aloud; personal voices start faster after the
  first time (Windows) and say dates and numbers as words; cleaner PDF text; clean titles and
  authors in the library; a Study tab and a side panel for Tools on wide screens.
- 1.14.0: books already in the library are not imported twice; RTF import; Open with ThingsBook on
  Android.
- 1.13.0: Kindle (MOBI/AZW3), Word, OpenDocument, FictionBook, comic (.cbz), Markdown and
  web-page import; PDFs up to 500 MB (other formats 100 MB); library search covers PDF text;
  recognized scan text is kept; faster, lighter storage and backups.

Updating from 1.12.5 or earlier: your library is converted in the background. Going back to
1.12.5 afterwards does not open books stored as pieces, and 1.12.5 cannot restore version 2
backups. Update every device before moving a library.

Limits: DRM-protected books are refused, never decrypted. Legacy .doc and password-protected
documents need a usable copy saved first. A malformed or protected book can still require a usable
original. Scan clarity affects OCR accuracy and recognition delay. Android saves at most 1 GB per
export, which also caps backup size there.

Not finished: native Android UI/storage/search migration, semantic search, private sync, precise
EPUB CFI annotations, human voice review, and the remaining Unified v5 requirements.

Verification: the portable regression suite (node work/run-tests.cjs) and the Rust core tests can be run on any computer (CI may be unavailable). This file does not claim physical-device or installed-release acceptance; check the GitHub
release notes for what was verified on a given build.

Building from source: see "Build" and "Making a release" in README.md. Do not overwrite verified
releases. No private libraries, recordings, voice models, backups or signing material are in this
repository.
